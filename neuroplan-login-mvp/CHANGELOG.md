# 변경 이력

## 0.8.0 — 2026-09-01

- Cloudflare Workers AI `@cf/qwen/qwen3.8-27b` 연동과 UTF-8 JSON 응답 검증 추가
- 선택한 과목·수준·희망 학습 시간 기반 AI 3단계 학습 플랜 생성 및 `daily_plan_ai_meta` 연결
- 오답의 사용자 답안·정답·기존 해설 기반 AI 맞춤 피드백과 추천 행동 저장
- 오답·진단·학습 통계 기반 과목별 개인 맞춤 재학습 추천과 대기열 저장
- 최초 AI 사용 동의, 설명 스타일, 희망 학습 시간 설정 추가
- 사용자별 일일 토큰 한도·사용량·잔여량 표시와 중복 차감 방지 원장 기록 추가
- 우측 상단에 `오늘 남은 토큰 / 일일 한도` 숫자와 잔량 막대를 함께 표시
- 선택 과목·수준 기반 AI 객관식 5문제 생성과 생성 기록 기반 서버 채점 추가
- Cloudflare Account ID/API Token을 `neuroplan-llm-secrets`에서만 주입하도록 배포 구성 분리
- 외부 호출 인증·사용량 제한·시간 초과·잘못된 JSON 오류 분류와 정적 플랜 폴백 추가
- 신규 회원의 AI 기본 설정·일일 토큰 한도 자동 생성 추가
- AI 플랜·문제·오답 해설·재학습 추천 요청 중 중앙 로딩 표시와 중복 실행 방지 추가
- AI 플랜 본문의 번호·동그라미 번호·줄바꿈 실행 항목을 `실습 순서` 카드 목록으로 분리해 가독성 개선
- 새로고침 시 인증과 학습 데이터 로딩을 분리해 일부 조회 실패에도 로그인 세션 유지
- 별도 UI 목업 디렉터리를 제거하고 실제 프론트 파일을 `neuroplan-login-mvp/frontend`로 통합
- Smoke Test에 실제 AI 플랜·문제 생성·서버 채점·오답 해설·재학습 추천·토큰 차감 검증 추가
- 상단 AI 토큰 칩에서 의미가 불명확한 백분율을 제거하고 잔여 토큰·일일 한도·잔량 바를 표시
- AI 요청의 연결 끊김·타임아웃·잘못된 JSON을 사용자 안내로 변환하고 저장 상태·토큰 잔량을 재조회
- 게이트웨이 5xx 응답도 동일하게 처리해 이미 저장된 AI 결과와 토큰 사용량을 다시 확인
- 인증·학습 API를 캐시하지 않도록 보강해 새로고침 시 세션 확인 안정성 개선
- 프론트 정적 파일 캐시를 비활성화해 배포 뒤 HTML과 JavaScript가 서로 다른 버전으로 섞이지 않도록 보완
- AI 요청 전 화면이 두 번 그려진 뒤 외부 호출을 시작해 중앙 로딩 오버레이 표시를 보장
- AI 요청 로딩 오버레이를 최상위 고정 레이어로 전환하고 최소 0.8초 동안 표시하도록 보강
- AI 응답 경로에 게이트웨이 제한시간을 명시하고 동시 Refresh Token 갱신을 하나로 합쳐 응답 단절·의도하지 않은 로그아웃 방지
- 가입일과 관리자 사용자 시각을 `Asia/Seoul` 기준으로 표시
- 기본 일일 AI 토큰을 5,000에서 20,000으로 높이고 기존 기본 한도 계정도 자동 상향
- On-Prem 통합 테스트 전 릴리스 후보 상태이며, 통과 후 최종 릴리스·태그 처리 예정
